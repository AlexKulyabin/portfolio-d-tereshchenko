# Что нужно от заказчика для запуска сайта

Чем полнее заполнено, тем меньше правок потом. Пункты, помеченные **[блокер]**,
нужны до начала работы — без них этап встанет.

---

## 1. Контакты **[блокер]**

- Телефон для сайта (в формате +7 …), можно ли по нему звонить с мобильных кнопок
- Второй телефон / WhatsApp / Telegram — если отличаются
- E-mail для заявок
- Часы работы
- Город базирования, география выездов (формулировка «по России» подтверждаем)
- Куда присылать уведомления о заявках: Telegram, e-mail или оба
  (для Telegram нужно будет один раз написать боту — инструкцию дам)

## 2. Юридические данные **[блокер для рекламы]**

- Статус: ИП, ООО или самозанятый
- Полное наименование / ФИО
- ИНН, ОГРН или ОГРНИП
- Юридический адрес (если ИП — можно только город)

Без этого объявления не пройдут модерацию в Яндекс.Директе, и нельзя корректно
оформить политику обработки персональных данных.

## 3. Об эксперте **[блокер]**

- ФИО и как подписываться на сайте
- Должность / позиционирование («эксперт по охране труда», «инженер по ОТ и ПБ» и т. п.)
- Профессиональное фото (горизонтальное и вертикальное, от 1500 px по длинной стороне;
  если нет — подскажу, как снять на телефон приемлемо)
- Опыт: сколько лет в профессии, где работал
- Образование, курсы, аттестации
- Сертификаты, удостоверения, свидетельства — сканы или фото (покажем как подтверждения)
- Членство в профильных организациях, если есть
- Цифры, которые не стыдно показать: число выполненных проектов, обслуженных
  предприятий, отраслей

## 4. Цены **[блокер]**

Для каждой из трёх услуг — три пакета. Шаблон:

| Услуга | Пакет | Цена | Что входит | Срок |
| --- | --- | --- | --- | --- |
| Оценка профрисков | Базовый | | | |
| Оценка профрисков | Стандарт | | | |
| Оценка профрисков | Под ключ | | | |
| Нормирование труда | Базовый | | | |
| Нормирование труда | Стандарт | | | |
| Нормирование труда | Под ключ | | | |
| Разработка ХАССП | Базовый | | | |
| Разработка ХАССП | Стандарт | | | |
| Разработка ХАССП | Под ключ | | | |

Уточнить:
- Цена фиксированная или «от»? От чего зависит (число рабочих мест, сотрудников,
  площадь, число технологических линий)?
- Есть ли доплата за выезд и как считается
- Есть ли скидка при заказе нескольких услуг
- Что входит в стоимость выезда

## 5. Содержание услуг

Для каждой услуги — можно тезисами, тексты напишем сами:

- Кому нужна услуга (отрасли, размер компании, повод: проверка, новое производство,
  требование заказчика)
- Что именно вы делаете по шагам
- Какие документы клиент получает на руки (полный перечень — это самый убедительный
  блок на странице)
- Сколько это занимает по факту
- Что нужно от клиента, чтобы начать
- Что бывает, если не сделать (штрафы, приостановка деятельности) — с ссылкой на норму,
  если знаете
- Частые вопросы клиентов и ваши ответы на них (по 4–6 на услугу — это готовый блок FAQ)

## 6. Подтверждения и социальные доказательства

- Отзывы клиентов: текст, компания, должность, разрешение на публикацию
- Логотипы клиентов — если можно публиковать
- Обезличенные примеры документов (титульный лист карты оценки рисков, фрагмент
  рабочего листа ХАССП) — очень сильно работают на доверие
- Фото с объектов, где вы работали (без узнаваемых лиц и коммерческой тайны)
- Отрасли, с которыми работали

## 7. Технические доступы

- Домен: уже есть или нужно подобрать и купить? Если есть — доступ к панели
  управления DNS
- Аккаунт Google для Firebase (можно создать отдельный под проект)
- Существующая Яндекс.Метрика — или создаём новую
- Аккаунт Яндекс.Директа — если реклама уже настраивалась
- Логин и пароль администратора для админки сайта (придумайте, задам в системе)
- Логотип в векторе, если есть; если нет — сделаем текстовый знак

## 8. Пожелания по оформлению

- Примеры сайтов, которые нравятся (2–3 ссылки) и что именно в них нравится
- Примеры, которые категорически не нравятся
- Есть ли фирменные цвета, кроме синего из ТЗ
- Обращение к клиенту: «вы» или «Вы»
- Тон: строгий официальный или деловой, но человеческий (рекомендую второе —
  лучше конвертит)

## 9. Отдельно уточнить

- Работаете с юрлицами, ИП или и с теми и с другими? От этого зависят формулировки
- Есть ли договор-оферта или типовой договор, который можно выложить
- Нужен ли раздел «Блог» / «Полезное» в перспективе (влияет на архитектуру)
- Нужен ли онлайн-калькулятор стоимости (рекомендую — заметно повышает конверсию
  рекламного трафика)
- Готовы ли подать уведомление в Роскомнадзор об обработке персональных данных
  (обязательно, если на сайте есть форма; подаётся бесплатно через портал РКН)

---

## Что делаем, пока данных нет

Работу не останавливаем: тексты услуг, FAQ и описания пакетов пишем сами на основе
нормативных требований, контакты и цены ставим заглушками. Но **все нормативные
ссылки, сроки и состав документов заказчик обязан вычитать до публикации** — в этой
сфере фактическая ошибка на сайте вредит репутации сильнее, чем её отсутствие.
