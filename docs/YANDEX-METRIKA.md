# Яндекс.Метрика: счётчик и цели

На сайте настроен счётчик **111979010**. Номер хранится в опубликованных настройках сайта
и может быть заменён через админку без изменения кода. Метрика загружается только после
согласия посетителя на аналитические cookies; Вебвизор отключён.

## Цели

Все цели создаются в интерфейсе Метрики как «Целевое событие / JavaScript-событие».
Идентификатор в Метрике должен совпадать с идентификатором из таблицы.

| Идентификатор | Что означает | Дополнительный контекст |
| --- | --- | --- |
| `form_submit` | Заявка успешно сохранена сервером | направление, источник перехода к форме, пакет |
| `click_phone` | Нажат номер или кнопка звонка | направление и место кнопки |
| `click_whatsapp` | Нажат WhatsApp | направление и место кнопки |
| `click_telegram` | Нажат Telegram | направление и место кнопки |
| `click_email` | Нажата электронная почта | направление и место ссылки |
| `service_open` | Нажата внутренняя ссылка на услугу | выбранное направление и место ссылки |
| `cta_click` | Нажата кнопка «Получить расчёт» | направление и место кнопки |
| `package_select` | Нажата кнопка выбора пакета | направление, название и номер пакета |
| `form_start` | Первый переход в поле формы | направление, источник перехода к форме, пакет |

`form_submit` срабатывает только после успешного приёма заявки. Ошибочная или отклонённая
отправка конверсией не считается. `form_start` срабатывает один раз для одного показа формы.

## Параметры событий

Сайт передаёт параметры, по которым одно событие можно разделять в отчётах:

| Параметр | Значение |
| --- | --- |
| `service` | направление услуги, `general` для общего интереса или `multiple` для нескольких услуг |
| `page` | адрес страницы, на которой произошло действие |
| `placement` | место элемента: шапка, первый экран, тарифы, форма, подвал и т. п. |
| `package` | название выбранного пакета, только для связанных действий |
| `package_index` | порядковый номер пакета, только для `package_select` |

Значения `service` для трёх направлений:

- `otsenka-professionalnyh-riskov` — оценка профессиональных рисков;
- `normirovanie-truda` — нормирование труда;
- `razrabotka-hassp` — система ХАССП.

Основные значения `placement`: `header_desktop`, `header_mobile`, `hero_home`,
`hero_service`, `services_grid`, `pricing`, `cta_block`, `lead_form`, `contacts_page`,
`footer`, `mobile_bar`. Они позволяют понять, какая именно кнопка дала обращение.

Если посетитель выбирает услугу или пакет и затем переходит к форме, сайт на 30 минут
запоминает этот технический контекст в пределах вкладки браузера. Он удаляется после
успешной заявки. Контактные и иные персональные данные в Метрику не передаются.

## Как проверить после публикации

1. Открыть сайт в приватном окне без блокировщика рекламы.
2. Разрешить аналитические cookies в уведомлении сайта.
3. Открыть одну из услуг через карточку, нажать «Получить расчёт» или выбрать пакет.
4. Поставить курсор в поле формы. Реальную тестовую заявку отправлять только с явно
   тестовыми контактами и затем удалить её из CRM и почты.
5. В Метрике открыть отчёт по целям и параметры событий. Убедиться, что появились
   нужные идентификаторы и значения `service`, `placement`, `page`.

Данные в стандартных отчётах могут появляться не мгновенно. Если посетитель отказался
от аналитических cookies, его действия намеренно не попадут в Метрику, но форма и все
контактные ссылки продолжат работать.
